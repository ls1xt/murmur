Create `.github/workflows/ci.yml`. Start by creating the directory:
```bash
mkdir -p .github/workflows
```

Then write the following workflow file:

```yaml
name: CI

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  ci:
    name: Python ${{ matrix.python-version }} / ${{ matrix.os }}
    runs-on: ${{ matrix.os }}
    strategy:
      fail-fast: true
      matrix:
        os: [ubuntu-latest, macos-latest]
        python-version: ["3.11", "3.12"]

    steps:
      - uses: actions/checkout@v4

      - name: Setup virtual audio (Linux)
        if: runner.os == 'Linux'
        run: sudo modprobe snd-aloop

      - name: Setup virtual audio (macOS)
        if: runner.os == 'macOS'
        env:
          HOMEBREW_NO_AUTO_UPDATE: "1"
        run: brew install blackhole-2ch

      - name: Set up Python ${{ matrix.python-version }}
        uses: actions/setup-python@v5
        with:
          python-version: ${{ matrix.python-version }}

      - name: Install uv
        uses: astral-sh/setup-uv@v5

      - name: Install dependencies
        run: uv sync --group dev

      - name: Run pre-commit
        run: uv run pre-commit run --all-files

      - name: Lint (ruff)
        run: uv run ruff check .

      - name: Format check (ruff)
        run: uv run ruff format --check .

      - name: Type check (pyright)
        run: uv run pyright

      - name: Unit tests
        run: uv run pytest

      - name: Audio pipeline tests (virtual mic)
        run: uv run pytest --virtual-mic
```

Key implementation notes:
- `fail-fast: true` is the default; explicit here for clarity (per CONTEXT.md)
- Virtual audio setup steps use `if: runner.os == 'Linux'` and `if: runner.os == 'macOS'` (not `matrix.os` value comparison, which is fragile)
- `HOMEBREW_NO_AUTO_UPDATE: "1"` prevents brew from updating itself before installing BlackHole — saves ~2 minutes on macOS runners
- `astral-sh/setup-uv@v5` handles both uv installation and optional dependency caching
- `uv sync --group dev` installs all deps including dev group using the uv.lock lockfile (reproducible)
- `pre-commit run --all-files` runs as a CI step using the project's own uv env (pre-commit must be in dev deps — confirmed in plan 08-02)
- `pyright` runs directly via `uv run pyright` (NOT via pre-commit) so it uses the project's `.venv` with all stubs
- Unit tests (`pytest`) and virtual-mic tests (`pytest --virtual-mic`) are separate steps so failures are distinguishable in the CI log
- The `--virtual-mic` step runs AFTER the virtual audio setup step; snd-aloop is synchronous (device available immediately after modprobe); BlackHole is available after brew install completes

Do NOT add any caching steps — `astral-sh/setup-uv@v5` includes built-in uv caching. Adding explicit `actions/cache` would be redundant.
