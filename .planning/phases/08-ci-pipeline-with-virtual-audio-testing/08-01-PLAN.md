**Step 3: Add virtual_mic_device session-scoped fixture**

Add this fixture after the existing fixtures at the bottom of conftest.py:

```python
import sys
from collections.abc import Generator


@pytest.fixture(scope="session")
def virtual_mic_device(request: pytest.FixtureRequest) -> Generator[str | int, None, None]:
    """Yield the virtual mic device name or index for audio pipeline tests.

    On Linux: detects snd-aloop ALSA loopback device by name (contains 'loopback').
    On macOS: detects BlackHole virtual audio device by name (contains 'blackhole').

    Skips the test session if no suitable virtual device is found.
    """
    import sounddevice as sd  # type: ignore[import-untyped]

    devices = sd.query_devices()
    if sys.platform == "linux":
        for i, dev in enumerate(devices):
            name: str = dev["name"].lower()
            max_in: int = int(dev["max_input_channels"])
            if max_in > 0 and "loopback" in name:
                yield i
                return
    elif sys.platform == "darwin":
        for i, dev in enumerate(devices):
            name = dev["name"].lower()
            max_in = int(dev["max_input_channels"])
            if max_in > 0 and "blackhole" in name:
                yield dev["name"]
                return
    pytest.skip(
        "No virtual mic device found — load snd-aloop (Linux) or install BlackHole (macOS)"
    )
```

Important notes:
- The `import sys` may already be in the file; check and don't duplicate it.
- The `from collections.abc import Generator` import must be added if not already present.
- `sounddevice` is an existing project dependency — no new dependency needed.
- Keep `from __future__ import annotations` at the top if it's already there.
- The fixture uses `scope="session"` so device enumeration happens once per test run.
- Do NOT add `unused-variable` or type-ignore comments beyond what's needed for pyright strict mode. The `request: pytest.FixtureRequest` parameter is standard for session fixtures even if unused in body.
