Add an SNI backend class alongside the existing pystray code. The `TrayIcon.start()` method already has a Sway guard -- replace the no-op log message with the SNI implementation.

**1. Add `_SniTray` helper class** (private, module-level) that encapsulates the D-Bus SNI lifecycle:

- `__init__(self, on_quit: Callable | None)`: Store callback, initialize state to `"idle"`, set `_conn`, `_owner_id`, `_reg_id`, `_loop` to None.

- `start(self) -> None`:
  - Define the SNI XML interface string (minimal: Category, Id, Status, Title, IconName, IconPixmap, ItemIsMenu properties; Activate and ContextMenu methods; NewIcon and NewStatus signals). Use the exact XML from the research doc.
  - Parse with `Gio.DBusNodeInfo.new_for_xml(xml)`
  - Get session bus: `Gio.bus_get_sync(Gio.BusType.SESSION, None)`
  - Register object at `/StatusNotifierItem` with `conn.register_object()` passing `_handle_method_call`, `_handle_get_property`, None
  - Own bus name `f'org.kde.StatusNotifierItem-{os.getpid()}-1'` via `Gio.bus_own_name()` with `_on_name_acquired` callback
  - Start `GLib.MainLoop()` in a daemon thread

- `_on_name_acquired(self, conn, name, data)`: Call `RegisterStatusNotifierItem` on `org.kde.StatusNotifierWatcher` with the owned bus name.

- `_handle_method_call(self, conn, sender, path, iface, method, params, invocation)`:
  - `Activate`: call `self._on_quit()` if set (left-click = quit, simplest behavior)
  - `ContextMenu`: no-op
  - Return empty tuple for both via `invocation.return_value(None)`

- `_handle_get_property(self, conn, sender, path, iface, prop_name) -> GLib.Variant`:
  - `Category`: `GLib.Variant('s', 'ApplicationStatus')`
  - `Id`: `GLib.Variant('s', 'murmur')`
  - `Status`: `GLib.Variant('s', 'Active')`
  - `Title`: `GLib.Variant('s', f'Murmur - {title}')`
  - `IconName`: `GLib.Variant('s', '')` (empty -- we use pixmap)
  - `IconPixmap`: `GLib.Variant('a(iiay)', [(64, 64, self._make_pixmap_bytes())])`
  - `ItemIsMenu`: `GLib.Variant('b', False)`

- `_make_pixmap_bytes(self) -> bytes`: Use `_create_icon_image(self._state)` (the existing function) to get a PIL RGBA image. Convert RGBA to ARGB big-endian byte order: for each pixel, reorder `(R, G, B, A)` to `(A, R, G, B)`.

- `set_state(self, state: str) -> None`: Update `self._state`, then `GLib.idle_add(self._emit_new_icon)` for thread-safe signal emission.

- `_emit_new_icon(self) -> bool`: Emit `NewIcon` signal via `self._conn.emit_signal(None, '/StatusNotifierItem', 'org.kde.StatusNotifierItem', 'NewIcon', None)`. Return False (don't repeat).

- `stop(self) -> None`: Quit the GLib main loop, unregister object, unown name.

**2. Modify `TrayIcon.start()`:**
- In the `not self._appindicator_works()` branch: instead of logging and returning, create `self._sni = _SniTray(on_quit=self._on_quit)`, call `self._sni.start()`, set `self._available = True`, and set `self._use_sni = True`.

**3. Modify `TrayIcon.set_state()`:**
- If `self._use_sni` is True, delegate to `self._sni.set_state(state)` instead of updating the pystray icon.

**4. Modify `TrayIcon.stop()`:**
- If `self._use_sni` is True, call `self._sni.stop()`.

**5. Keep all existing pystray code unchanged** -- it continues to work on non-Sway compositors.

**Important from research:**
- Object path MUST be exactly `/StatusNotifierItem`
- Register object BEFORE owning bus name
- Bus name follows `org.kde.StatusNotifierItem-{PID}-{N}` convention
- IconPixmap is ARGB32 big-endian (swap from Pillow's RGBA)
- `_handle_get_property` is called from GLib thread -- no need for `idle_add` there
- Only `set_state()` (called from app thread) needs `idle_add`
