2. Implement `inject_raw(self, text: str) -> None`:
   - If `not text`: return
   - Use `ydotool type --clearmodifiers -- {text}` directly (no trailing space, no clipboard strategy routing)
   - Same error handling as `_inject_via_ydotool` but without the `_trailing_space` addition
   - Log at DEBUG level: `"Injecting raw partial: %r"` (truncated to 80 chars)

   - If `count <= 0`: return
   - Use `ydotool type` with backspace characters: `self._ydotool_path, "type", "--clearmodifiers", "--", "\x08" * count`
   - The `\x08` character is interpreted by ydotool as backspace
   - Log at DEBUG level: `"Injecting %d backspaces"`
   - Same timeout and error handling pattern as other injection methods
   - If `\x08` approach doesn't work, fall back to `ydotool key` with keycode 14 (KEY_BACKSPACE): generate pairs `"14:1", "14:0"` repeated `count` times

<task type="auto">
  <name>Task 2: Delta partial injection in DictationApp and audio feedback upgrade</name>

  <action>
**main.py changes -- delta partial injection:**

1. Add `self._last_partial: str = ""` and `self._inject_lock = threading.Lock()` to `DictationApp.__init__`.

2. Rewrite `_on_partial_transcript(self, text: str) -> None`:
   ```
   if not text:
       return
   with self._inject_lock:
       if text.startswith(self._last_partial):
           # Common case: AssemblyAI appended words
           suffix = text[len(self._last_partial):]
           if suffix:
               self.injector.inject_raw(suffix)
       else:
           # Diverged: backspace the old partial, type new text
           if self._last_partial:
               self.injector.inject_backspaces(len(self._last_partial))
           self.injector.inject_raw(text)
       self._last_partial = text
   ```
   Keep the existing `logger.debug("Partial: %s", text)` line.

3. Rewrite `_on_final_transcript(self, text: str) -> None`:
   ```
   with self._inject_lock:
       # Backspace the partial first
       if self._last_partial:
           self.injector.inject_backspaces(len(self._last_partial))
           self._last_partial = ""
       if not text.strip():
           return
       logger.info("Injecting: %s", text)
       try:
           self.injector.inject(text)
       except Exception as e:
           logger.error("Text injection failed: %s", e)
   ```

4. In `_on_deactivate`, add `self._last_partial = ""` to reset partial state when recording stops. Place it after the `self.transcriber.stop()` thread start.

5. Wrap the existing `self.injector.inject(text)` call in `_on_final_transcript` with `self._inject_lock` to prevent races between partial and final injection (both called from AssemblyAI's callback thread).

**audio.py changes -- error visibility upgrade:**

6. In `_get_pa()`, change `logger.debug("PyAudio init failed: %s", e)` to `logger.warning("PyAudio init failed (audio feedback unavailable): %s", e)`.

7. In `AudioFeedback._play_tone`, change `logger.debug("Audio feedback error: %s", e)` to:
   ```python
   if not hasattr(AudioFeedback, '_audio_warned'):
       logger.warning("Audio feedback error: %s", e)
       AudioFeedback._audio_warned = True
   else:
       logger.debug("Audio feedback error: %s", e)
   ```
   This logs the first failure at WARNING (visible), subsequent failures at DEBUG (not spammy).
