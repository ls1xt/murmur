  <action>
Create `murmur/errors.py` with:

1. `fatal(message: str) -> None` function that:
   - Logs via `logger.error(message)`
   - Prints `"murmur: {message}"` to stderr
   - Runs `subprocess.run(["notify-send", "--urgency=critical", "Murmur", message], timeout=5, capture_output=True)` wrapped in try/except for FileNotFoundError and TimeoutExpired (non-fatal if notify-send missing)
   - Calls `sys.exit(1)`

2. `fatal_from_thread(message: str) -> None` function that:
   - Same as `fatal()` but uses `os.kill(os.getpid(), signal.SIGTERM)` instead of `sys.exit(1)` since sys.exit only raises SystemExit in the calling thread
   - Import signal and os at module top

Update `murmur/main.py`:
- Replace the existing `if not self.injector.is_available()` block in `run()` with a call to `fatal()` with message: `"ydotoold is not running. Start it with: systemctl --user start ydotool"`. The existing `is_available()` method already does the pgrep check.
- Replace the `if not config.transcriber.api_key` block in `main()` with `fatal("ASSEMBLYAI_API_KEY not set. Get a key at: https://www.assemblyai.com/")`
- Import fatal from murmur.errors

Create `tests/test_errors.py`:
- Test `fatal()` exits with code 1 (use `pytest.raises(SystemExit)`)
- Test `fatal()` prints to stderr (capture capsys)
- Test `fatal()` calls notify-send subprocess (mock subprocess.run)
- Test `fatal()` handles missing notify-send gracefully (mock subprocess.run raising FileNotFoundError)
- Test `fatal_from_thread()` sends SIGTERM (mock os.kill)

Update existing tests in `tests/test_main.py` or add new tests:

- Test startup exits when API key missing
