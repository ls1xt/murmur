Update `murmur/hotkey/evdev.py`:

In `_listen_loop()`, the current `except OSError` block at line ~157 does:
```python
except OSError:
    dev_path: str = str(device.path)
    logger.warning("Device disconnected: %s", dev_path)
    selector.unregister(device)
```

Replace with:
```python
except OSError:
    dev_path: str = str(device.path)
    from murmur.errors import fatal_from_thread
    fatal_from_thread(f"Input device disconnected: {dev_path}")
```

This ensures the daemon exits immediately on ANY device read error rather than continuing in a degraded state. Per user decision: no attempt to recover key state or re-acquire the device.

Import note: Use lazy import inside the except block to avoid circular imports (errors.py is simple, but keep the pattern consistent with how other modules use it).
