<objective>
Implement three text injection strategies so non-ASCII characters (curly quotes, em-dashes, accented chars) are handled correctly.

Purpose: ydotool's `type` command only handles basic Latin characters. Curly quotes, em-dashes, and accented characters from speech-to-text output are silently dropped or garbled. A clipboard-based fallback (`wl-copy` + Ctrl+V via ydotool) handles all Unicode correctly.

Output: Three injection strategies selectable via `--inject` CLI flag, with `clipboard-fallback` as the default.
</objective>

4. Add `_inject_via_clipboard(self, text: str) -> None` method:
   ```python
   def _inject_via_clipboard(self, text: str) -> None:
       """Inject text via clipboard: wl-copy + Ctrl+V."""
       if not self._wl_copy_path:
           from murmur.errors import fatal
           fatal("wl-copy not found. Install wl-clipboard: pacman -S wl-clipboard")

       # Write to clipboard
       result = subprocess.run(
           [self._wl_copy_path, "--", text],
           timeout=5,
           capture_output=True,
           text=True,
       )
       if result.returncode != 0:
           logger.error("wl-copy failed: %s", result.stderr.strip())
           return

       # Simulate Ctrl+V paste
       result = subprocess.run(
           [self._ydotool_path, "key", "29:1", "47:1", "47:0", "29:0"],
           timeout=5,
           capture_output=True,
           text=True,
       )
       if result.returncode != 0:
           logger.error("ydotool key failed: %s", result.stderr.strip())
   ```
   Note: keycodes 29=KEY_LEFTCTRL, 47=KEY_V. Format `code:value` where 1=press, 0=release.
