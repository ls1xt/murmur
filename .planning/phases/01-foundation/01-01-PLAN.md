- Define `HotkeyListener` as an ABC with:

  - `start()` — abstract
  - `stop()` — abstract
  - `_handle_hotkey_press()` / `_handle_hotkey_release()` — concrete methods for mode logic (push_to_talk vs toggle). In toggle mode, maintain a `self._active: bool` state and fire activate/deactivate alternately.
- Use pattern from RESEARCH.md "Pattern 1: ABC Base Class Structure".

- `def create_hotkey_listener(config: HotkeyConfig) -> HotkeyListener`
- Use `match config.backend` pattern from RESEARCH.md "Pattern 2: Factory Function".
- Cases: `"evdev"` → lazy import `EvdevHotkeyListener`, `"auto"` → detect platform (`sys.platform == "linux"` → evdev), `case _` → raise ValueError.
- Import `HotkeyConfig` from `murmur.config`, `HotkeyListener` from `murmur.hotkey.base`.

- Keep all logic unchanged.
