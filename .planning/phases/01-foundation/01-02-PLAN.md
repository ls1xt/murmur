**Expected error categories and fixes (from RESEARCH.md):**

1. **`reportMissingModuleSource` for evdev, pyaudio:**
   - Already suppressed globally via `reportMissingModuleSource = "none"` in pyproject.toml.
   - If `import-untyped` errors still appear, add `# type: ignore[import-untyped]` at the import site for `evdev` and `pyaudio`.

2. **`reportUnknownParameterType` / `reportMissingParameterType`:**
   - Every function parameter needs a type annotation.
   - `_signal_handler(signum, frame)` in main.py → annotate as `signum: int, frame: types.FrameType | None`.
   - Lambda defaults in dataclass fields should be typed: `field(default_factory=lambda: ["KEY_LEFTCTRL", "KEY_LEFTSHIFT"])` — this is OK, Pyright infers `list[str]` from the field type annotation.

3. **`reportUnknownMemberType` for evdev and assemblyai SDK:**
   - evdev's `ecodes.ecodes.get(name)` returns unknown type — annotate the result: `code: int | None = ecodes.ecodes.get(name)`.
   - evdev's `categorize(event)` returns `KeyEvent | AbsEvent | ...` — may need a cast or type narrowing.
   - AssemblyAI SDK callback signatures: fix `Type[StreamingClient]` to `StreamingClient` (it's the instance, not the class). Verify by checking the SDK's actual signatures.

4. **`reportUnknownVariableType` in config.py `_from_dict`:**
   - `setattr(config.hotkey, k, v)` where `v` is `Any` from JSON dict. This is a known pitfall.
   - Fix: annotate `data: dict[str, Any]` explicitly (accepting `Any` here is intentional for JSON deserialization). Add targeted `# type: ignore[reportUnknownArgumentType]` if needed, with a `# TODO: type-safe deserialization` comment.

5. **`reportUntypedBaseClass` if ABCs have issues:**
   - Ensure all ABCs properly inherit from `ABC` and all abstract methods use `@abstractmethod`.

6. **Missing return type annotations:**
   - Every function/method needs `-> ReturnType`. Check `__init__` methods → `-> None`.

**General approach:**
- Work module-by-module: `config.py` → `hotkey/base.py` → `hotkey/evdev.py` → `transcriber/base.py` → `transcriber/assemblyai.py` → `injector/base.py` → `injector/ydotool.py` → `feedback/audio.py` → `main.py`
