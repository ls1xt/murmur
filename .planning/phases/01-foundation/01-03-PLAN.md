Use the pattern from RESEARCH.md "pytest conftest.py — Hardware Skip Logic":

```python
from __future__ import annotations
import pytest

def pytest_addoption(parser: pytest.Parser) -> None:
    parser.addoption(
        "--hardware",
        action="store_true",
        default=False,
        help="Run integration tests requiring real hardware",
    )

def pytest_collection_modifyitems(
    config: pytest.Config,
    items: list[pytest.Item],
) -> None:
    if config.getoption("--hardware"):
        return
    skip_marker = pytest.mark.skip(reason="hardware tests skipped (use --hardware to run)")
    for item in items:
        if item.get_closest_marker("hardware"):
            item.add_marker(skip_marker)
```

Note: `from __future__ import annotations` is needed here because `list[pytest.Item]` in function signatures requires it for pytest's internal type handling on Python 3.10.
