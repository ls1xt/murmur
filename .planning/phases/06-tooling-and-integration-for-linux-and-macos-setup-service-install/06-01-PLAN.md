# Plan 06-01: Service Tooling Refactor (murmur.service, murmur.plist, install-service.sh)

## Goal

Fix the fragile hardcoded-path approach in the Linux service tooling and extend `install-service.sh` to support macOS LaunchAgent installation. Create `murmur.plist` as the macOS counterpart to `murmur.service`.

## Context

`murmur.service` currently has a hardcoded old developer path (`%h/dev/python/murmur`) in the Documentation field and in ExecStart. `install-service.sh` replaces this string with `$SCRIPT_DIR` via sed, which breaks if the string doesn't match. The fix: use `@@MURMUR_DIR@@` as a clean placeholder token throughout both the service file and a new plist template.

<title>Fix murmur.service — replace hardcoded paths with @@MURMUR_DIR@@ placeholder</title>
<file>murmur.service</file>

Current:

After:

Full resulting file:
```ini
[Unit]

Documentation=file://@@MURMUR_DIR@@/README.md
After=graphical-session.target sound.target
PartOf=graphical-session.target

[Service]
Type=simple
ExecStart=@@MURMUR_DIR@@/.venv/bin/murmur
Restart=on-failure
RestartSec=3

# Pass through display/audio environment from the user session
Environment=PATH=/usr/local/bin:/usr/bin:/bin
PassEnvironment=DISPLAY WAYLAND_DISPLAY XDG_RUNTIME_DIR DBUS_SESSION_BUS_ADDRESS PULSE_SERVER

[Install]
WantedBy=graphical-session.target
```

<task id="06-01-02">
<title>Create murmur.plist — macOS LaunchAgent template with @@MURMUR_DIR@@ placeholder</title>
<file>murmur.plist</file>
<description>
Create `murmur.plist` in the repo root alongside `murmur.service`. This is a template — `@@MURMUR_DIR@@` will be substituted with the actual project path by `install-service.sh`.

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>com.murmur.daemon</string>
    <key>ProgramArguments</key>
    <array>
        <string>@@MURMUR_DIR@@/.venv/bin/murmur</string>
    </array>
    <key>RunAtLoad</key>
    <true/>
    <key>KeepAlive</key>
    <dict>
        <key>SuccessfulExit</key>
        <false/>
    </dict>
    <key>StandardOutPath</key>
    <string>/tmp/murmur.log</string>
    <key>StandardErrorPath</key>
    <string>/tmp/murmur.log</string>
</dict>
</plist>
```

Semantics:
- `RunAtLoad: true` — starts automatically on login
- `KeepAlive.SuccessfulExit: false` — restarts on crash, not on clean exit (matches `Restart=on-failure` in systemd)
- Log paths go to `/tmp/murmur.log` for easy access during development
</description>
</task>

<task id="06-01-03">
<title>Overhaul install-service.sh — clean placeholder substitution + macOS branch</title>
<file>install-service.sh</file>
<description>
Rewrite `install-service.sh` to:
1. Detect OS via `uname -s`
2. On Linux: substitute `@@MURMUR_DIR@@` in `murmur.service` and install to systemd
3. On macOS: substitute `@@MURMUR_DIR@@` in `murmur.plist` and install to `~/Library/LaunchAgents/`

```bash
#!/usr/bin/env bash
set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
OS="$(uname -s)"

# Verify venv exists
[ -f "$SCRIPT_DIR/.venv/bin/murmur" ] || { echo "ERROR: Run ./setup.sh first (venv not found)"; exit 1; }

case "$OS" in
    Linux*)
        SERVICE_DIR="$HOME/.config/systemd/user"
        SERVICE_NAME="murmur.service"

        mkdir -p "$SERVICE_DIR"

        sed "s|@@MURMUR_DIR@@|$SCRIPT_DIR|g" "$SCRIPT_DIR/$SERVICE_NAME" \
            > "$SERVICE_DIR/$SERVICE_NAME"

        systemctl --user daemon-reload
        systemctl --user enable --now murmur

        echo "Service installed and started."
        echo "  Status:  systemctl --user status murmur"
        echo "  Logs:    journalctl --user -u murmur -f"
        echo "  Stop:    systemctl --user stop murmur"
        ;;

    Darwin*)
        PLIST_DIR="$HOME/Library/LaunchAgents"
        PLIST_NAME="com.murmur.daemon.plist"

        mkdir -p "$PLIST_DIR"

        sed "s|@@MURMUR_DIR@@|$SCRIPT_DIR|g" "$SCRIPT_DIR/murmur.plist" \
            > "$PLIST_DIR/$PLIST_NAME"

        launchctl load "$PLIST_DIR/$PLIST_NAME"

        echo "LaunchAgent installed and started."
        echo "  Status:  launchctl list | grep murmur"
        echo "  Logs:    tail -f /tmp/murmur.log"
        echo "  Stop:    launchctl stop com.murmur.daemon"
        ;;

    *)
        echo "ERROR: Unsupported OS: $OS"
        echo "Supported: Linux, macOS (Darwin)"
        exit 1
        ;;
esac
```
</description>
</task>
