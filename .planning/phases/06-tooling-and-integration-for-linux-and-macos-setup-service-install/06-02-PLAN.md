# Plan 06-02: Cross-Platform setup.sh and run.sh

## Goal

Add macOS support to `setup.sh` (dependency installation) and `run.sh` (developer entrypoint). Both scripts currently assume Linux. After this plan, both work on Linux and macOS.

## Context

- `setup.sh` uses `/etc/os-release` distro detection (Linux-only). macOS needs a Homebrew branch.
- `run.sh` checks ydotoold, input group membership, and pipes stderr through an ALSA/JACK noise filter — all Linux-only concerns. On macOS, Accessibility permissions are already handled at runtime by `DictationApp.run()` (Phase 05-04), so no preflight checks for ydotoold/input are needed.
- Both scripts must detect OS via `uname -s` at the top and branch on `Linux*` vs `Darwin*`.

<title>Add macOS branch to setup.sh</title>
<file>setup.sh</file>
<description>
Rewrite `setup.sh` with top-level OS detection. The Linux logic is unchanged (moved into `Linux*` case). The macOS branch checks for Homebrew, installs portaudio, and runs `uv sync`.

```bash
#!/usr/bin/env bash
set -euo pipefail

echo "=== Murmur Setup ==="
echo ""

OS="$(uname -s)"

case "$OS" in
    Linux*)
        # Detect distro via /etc/os-release
        if [ -f /etc/os-release ]; then
            . /etc/os-release
            DISTRO="${ID:-unknown}"
        else
            DISTRO="unknown"
        fi

        echo "Detected: Linux ($DISTRO)"
        echo ""

        # Install system dependencies
        case "$DISTRO" in
            arch|manjaro|endeavouros)
                echo "Installing system dependencies via pacman..."
                sudo pacman -S --needed ydotool portaudio
                ;;
            ubuntu|debian|linuxmint|pop)
                echo "Installing system dependencies via apt..."
                sudo apt-get install -y ydotool portaudio19-dev
                ;;
            fedora)
                echo "Installing system dependencies via dnf..."
                sudo dnf install -y ydotool portaudio-devel
                ;;
            *)
                echo "WARNING: Unknown distro '$DISTRO'. Install ydotool and portaudio manually."
                ;;
        esac

        echo ""

        # Check input group membership
        if ! groups | grep -qw input; then
            echo "WARNING: You are not in the 'input' group."
            echo "  Run: sudo usermod -aG input \$USER"
            echo "  Then log out and back in."
            echo ""
        fi

        # Check ydotoold status
        if ! pgrep -x ydotoold > /dev/null 2>&1; then
            echo "WARNING: ydotoold daemon is not running."
            echo "  Start it: systemctl --user start ydotool"
            echo ""
        fi
        ;;

    Darwin*)
        echo "Detected: macOS"
        echo ""

        # Check for Homebrew
        if ! command -v brew &> /dev/null; then
            echo "ERROR: Homebrew is required but not installed."
            echo "  Install: /bin/bash -c \"\$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)\""
            exit 1
        fi

        echo "Installing system dependencies via Homebrew..."
        brew install portaudio

        echo ""
        echo "NOTE: Microphone and Accessibility permissions are required."
        echo "  These will be requested by macOS on first run."
        echo ""
        ;;

    *)
        echo "ERROR: Unsupported OS: $OS"
        echo "Supported: Linux, macOS (Darwin)"
        exit 1
        ;;
esac

# Create venv and install (both platforms)
echo "Running uv sync..."
uv sync

echo ""
echo "=== Setup complete ==="
echo "Run with: ./run.sh"
echo "Or activate manually: source .venv/bin/activate && python -m murmur"
```

<task id="06-02-02">
<title>Add macOS branch to run.sh</title>
<file>run.sh</file>
<description>
Rewrite `run.sh` with top-level OS detection. The Linux logic is unchanged (moved into `Linux*` case with the ALSA/JACK stderr filter). The macOS branch runs the same shared preflight checks (venv, API key, sounddevice) then launches murmur directly without the stderr filter.

```bash
#!/usr/bin/env bash
set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
CONFIG_FILE="$HOME/.config/murmur/config.json"
OS="$(uname -s)"

fail() { echo "ERROR: $*" >&2; exit 1; }
warn() { echo "WARNING: $*" >&2; }

# --- Shared preflight checks (all platforms) ---

# Check venv
[ -f "$SCRIPT_DIR/.venv/bin/murmur" ] || fail "No venv found. Run: ./setup.sh"

# Check API key
api_key_set=false
if [ -n "${ASSEMBLYAI_API_KEY:-}" ]; then
    api_key_set=true
elif [ -f "$CONFIG_FILE" ] && python3 -c "
import json, sys
data = json.load(open('$CONFIG_FILE'))
sys.exit(0 if data.get('transcriber', {}).get('api_key') else 1)
" 2>/dev/null; then
    api_key_set=true
fi
$api_key_set || fail "No API key configured. Run: ./config-api-key.sh"

# Check sounddevice can query an input device
if ! "$SCRIPT_DIR/.venv/bin/python" -c "import sounddevice; sounddevice.query_devices(kind='input')" &>/dev/null; then
    fail "No audio input device found. Check your microphone and audio system configuration."
fi

# Force Python to use unbuffered I/O so output appears immediately when piped
export PYTHONUNBUFFERED=1

# --- Platform-specific launch ---

case "$OS" in
    Linux*)
        # Check input group
        groups | grep -qw input || warn "Not in 'input' group — hotkey detection may fail. Run: sudo usermod -aG input \$USER"

        # Start ydotoold if not running
        if ! pgrep -x ydotoold > /dev/null 2>&1; then
            echo "Starting ydotoold..."
            systemctl --user start ydotool 2>/dev/null || ydotoold &
            sleep 0.5
            pgrep -x ydotoold > /dev/null 2>&1 || fail "ydotoold failed to start"
        fi

        # Silence PortAudio probe noise (ALSA + JACK warnings from device enumeration)
        export JACK_NO_AUDIO_RESERVATION=1

        "$SCRIPT_DIR/.venv/bin/murmur" "$@" 2> >(grep --line-buffered -v \
            -e "^ALSA lib" \
            -e "^JACK " \
            -e "^Cannot connect to server" \
            -e "^JackShmReadWritePtr" \
            -e "^jack server" \
            -e "^Cannot open device" \
            >&2)
        ;;

    Darwin*)
        # macOS: ydotoold not needed (uses pynput + pbcopy injector)
        # Accessibility permissions handled at runtime by DictationApp.run()
        # CoreAudio backend produces no ALSA/JACK noise — no stderr filter needed
        "$SCRIPT_DIR/.venv/bin/murmur" "$@"
        ;;

    *)
        fail "Unsupported OS: $OS (supported: Linux, macOS)"
        ;;
esac
```
