Refactor the `main()` function in murmur/main.py to use argparse subparsers. Keep the `DictationApp` class, `_SessionFilter`, and `_session_var` exactly as-is — only the `main()` function changes.

Subcommand structure:

```python
def main() -> None:
    parser = argparse.ArgumentParser(
        prog="murmur",
        description="System-wide voice dictation",
    )
    subparsers = parser.add_subparsers(dest="command", required=True)

    # murmur config [--key KEY] [--value VALUE]
    config_parser = subparsers.add_parser("config", help="View or set configuration")
    config_parser.add_argument("--key", help="Dot-separated config key (e.g. transcriber.api_key)")
    config_parser.add_argument("--value", help="Value to set for the given key")

    # murmur record [--inject ...] [--notify ...] [--inject-partials / --no-inject-partials]
    record_parser = subparsers.add_parser("record", help="Single dictation session (run once and exit)")
    record_parser.add_argument("--inject", choices=["ydotool", "clipboard-fallback", "clipboard"], default=None)
    record_parser.add_argument("--notify", choices=["off", "errors", "verbose"], default=None)
    record_parser.add_argument("--inject-partials", dest="inject_partials", action="store_true", default=None)
    record_parser.add_argument("--no-inject-partials", dest="inject_partials", action="store_false")

    # murmur daemon {start|stop|status|enable}
    daemon_parser = subparsers.add_parser("daemon", help="Manage background service")
    daemon_parser.add_argument(
        "action",
        choices=["start", "stop", "status", "enable"],
        help="start: run daemon; stop: send SIGTERM; status: check running; enable: install service",
    )

    args = parser.parse_args()
```

Implement each subcommand handler as a separate private function:

**`_cmd_config(args)`:**
- Load config via `DictationConfig.load()`
- If no `--key`: pretty-print the full config as JSON to stdout (use `json.dumps(dataclasses.asdict(config), indent=2)`)
- If `--key` only: print the value at that dotted path (e.g. `transcriber.api_key` → `config.transcriber.api_key`)
- If `--key` and `--value`: set the value, call `config.save()`, print confirmation
  - Dotted path setter: split on `.`, walk the dataclass hierarchy to set the field
- Import `dataclasses` at top of file (add to existing imports)

**`_cmd_record(args)`:**
- Apply CLI overrides to config (same pattern as the existing main() function)
- Set up logging the same way as the current main()
- Check for API key — if missing, call `_prompt_api_key_if_needed(config)` (defined in Plan 02's setup_wizard; for now just call fatal() with a helpful message: "API key not set. Run: murmur config --key transcriber.api_key --value YOUR_KEY")
- Call `DictationApp(config).run()`

**`_cmd_daemon(args)`:**
- `start`: same as `_cmd_record` but with foreground flag semantics. For now, just calls `_cmd_record(args)` (daemon management via systemd/launchctl is opt-in via `enable`)
- `stop`: find running murmur daemon PID via `pgrep -f "murmur daemon start"` or `pgrep -f "murmur record"` (subprocess), send SIGTERM. Print "Daemon stopped." or "No daemon running."
- `status`: same pgrep check, print "Daemon running (PID=N)" or "Daemon not running"
- `enable`: check if `install-service.sh` exists at the expected path (same directory as the murmur package or a well-known location), run it; or print instructions if not found

The `main()` function routes to the correct handler based on `args.command`.

Keep existing imports. Add `import dataclasses`, `import json`, `import os`, `import subprocess` (subprocess may already be unused — check current imports before adding).

Remove `config-api-key.sh` from the repo root (it is superseded by `murmur config --key transcriber.api_key --value ...`). Note: actually leave it for now since it's outside murmur/ — just note in a comment.
