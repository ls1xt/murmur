Create murmur/hotkey/pynput.py with PynputHotkeyListener(HotkeyListener).

Key implementation requirements:

1. EVDEV → PYNPUT CANONICAL TRANSLATION TABLE at module level. Map evdev names to canonical pynput Key values (generic, not left/right-specific) so listener.canonical() set membership works:
   - KEY_LEFTCTRL → Key.ctrl, KEY_RIGHTCTRL → Key.ctrl
   - KEY_LEFTALT → Key.alt, KEY_RIGHTALT → Key.alt
   - KEY_LEFTSHIFT → Key.shift, KEY_RIGHTSHIFT → Key.shift
   - KEY_LEFTMETA → Key.cmd, KEY_RIGHTMETA → Key.cmd
   - KEY_SPACE → Key.space, KEY_ENTER → Key.enter, KEY_BACKSPACE → Key.backspace
   - KEY_ESC → Key.esc, KEY_TAB → Key.tab, KEY_DELETE → Key.delete
   - KEY_A..KEY_Z, KEY_0..KEY_9 → KeyCode.from_char('a'..'z', '0'..'9') using the pattern:
     if name.startswith("KEY_") and len(name) == 5: return KeyCode.from_char(name[4].lower())

2. Internal _ResolvedBinding dataclass (or named tuple) holding:
   - modifiers: frozenset[Key | KeyCode] — canonical pynput keys
   - trigger: Key | KeyCode — canonical pynput key
   - action: str

3. _resolve_bindings(bindings: list[HotkeyBinding]) → list[_ResolvedBinding]: translates each binding's modifiers and trigger via the table above. Raises ValueError for unknown evdev names.

4. PynputHotkeyListener.__init__(bindings, push_to_talk_debounce_ms=300):
   - super().__init__()
   - self._bindings = _resolve_bindings(bindings)
   - self._held: set[Key | KeyCode] = set()
   - self._listener: keyboard.Listener | None = None
   (push_to_talk_debounce_ms is accepted for API compatibility but not used on macOS — no grab/suppress)

5. start() → None: create a fresh keyboard.Listener(on_press=self._on_press, on_release=self._on_release); call self._listener.start(). MUST create a new instance each call — pynput threads cannot be restarted.

6. stop() → None: if self._listener is not None, call self._listener.stop(); set self._listener = None; clear self._held.

7. _on_press(key) → None:
   - canonical = self._listener.canonical(key) if self._listener else key
   - self._held.add(canonical)
   - For each binding in self._bindings:
     if binding.trigger == canonical and binding.modifiers.issubset(self._held):
       self._dispatch_action(binding.action)

8. _on_release(key) → None:
   - canonical = self._listener.canonical(key) if self._listener else key
   - For each binding in self._bindings:
     if binding.trigger == canonical and binding.trigger in self._held:
       self._dispatch_release(binding.action)
   - self._held.discard(canonical)

DO NOT use GlobalHotKeys or HotKey.parse() — GlobalHotKeys silently fails for Ctrl+Alt on macOS (pynput GitHub issue #297, unresolved). Use raw Listener + manual set tracking as above.

DO NOT suppress events (no darwin_intercept). Per user decision: no key grabbing/suppression on macOS.

DO gate the pynput import inside the module (top-level import is fine since this file is only imported on darwin via the factory).

Use from __future__ import annotations. Use logger = logging.getLogger(__name__). Follow pyright strict-mode conventions matching the rest of the codebase (type annotations on all methods, avoid Any where possible).
