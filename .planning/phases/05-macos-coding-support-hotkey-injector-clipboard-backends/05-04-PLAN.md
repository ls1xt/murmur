<task type="auto">
  <name>Task 2: Add macOS permission checks to DictationApp.run()</name>
  <files>murmur/main.py</files>
  <action>
Update DictationApp.run() to call macOS permission checks before proceeding on darwin.

The existing startup block in run() currently is:
    if not self.injector.is_available():
        fatal("ydotoold is not running. Start it with: systemctl --user start ydotool")

Replace this with a platform-aware block:

    import sys as _sys
    if _sys.platform == "darwin":
        from murmur.platform.macos import check_accessibility, check_microphone
        if not check_accessibility():
            fatal(
                "Accessibility permission required for keyboard monitoring.\n"
                "Go to System Settings → Privacy & Security → Accessibility\n"
                "and enable Terminal (or your Python interpreter)."
            )
        if not check_microphone():
            fatal(
                "Microphone permission required for audio capture.\n"
                "Go to System Settings → Privacy & Security → Microphone\n"
                "and enable Terminal (or your Python interpreter)."
            )
    elif not self.injector.is_available():
        fatal(
            "ydotoold is not running. Start it with: systemctl --user start ydotool"
        )

Note: sys is already imported at the top of main.py as `import sys` — do NOT add a redundant import. Use sys.platform directly (not _sys). The inline `import sys as _sys` is just for explanation; use the existing `sys` name.

The darwin branch replaces the ydotoold check entirely for macOS: on darwin, pynput injection requires Accessibility (which is what check_accessibility covers), so calling self.injector.is_available() is redundant. The elif ensures that on linux, the original ydotoold check behavior is completely preserved.

Verify the existing `import sys` is present at the top of main.py before editing. sys is already imported in main.py — confirm this and use it directly.
