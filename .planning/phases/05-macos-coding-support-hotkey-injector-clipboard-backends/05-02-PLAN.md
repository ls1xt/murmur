  <action>
Create murmur/injector/pynput.py with PynputInjector(TextInjector).

Copy _sanitize_text() verbatim from murmur/injector/ydotool.py (same logic, same docstring), since it is a pure utility that both backends share. Do NOT import it from ydotool.py to avoid coupling the macOS backend to a Linux module.

Key implementation requirements:

1. PynputInjector.__init__(trailing_space=True, inject_strategy="clipboard-fallback"):
   - self._trailing_space = trailing_space
   - self._inject_strategy = inject_strategy
   - self._controller = keyboard.Controller()

2. is_available() → bool:
   Check Accessibility permission (pynput requires it on macOS):
   try:
     from ApplicationServices import AXIsProcessTrusted
     return bool(AXIsProcessTrusted())
   except ImportError:
     return True  # cannot verify without pyobjc; assume available

3. inject(text: str) → None:
   - if not text: return
   - text = _sanitize_text(text)
   - if not text: return
   - if self._trailing_space: text = text + " "
   - Dispatch by self._inject_strategy:
     "clipboard" → self._inject_via_clipboard(text)
     "clipboard-fallback" → Controller.type() if text.isascii() else _inject_via_clipboard(text)
     anything else ("pynput") → self._controller.type(text)

4. inject_raw(text: str) → None:
   Same as inject() but NO trailing space added. Apply _sanitize_text. Log debug: "Injecting raw partial: %r". Same strategy dispatch but call _controller.type() for pynput path (no trailing space means we can just call type directly).

5. inject_backspaces(count: int) → None:
   if count <= 0: return
   logger.debug("Injecting %d backspaces", count)
   for _ in range(count):
     self._controller.press(keyboard.Key.backspace)
     self._controller.release(keyboard.Key.backspace)

6. copy_to_clipboard(text: str) → None:
   Copy text to macOS clipboard via pbcopy. NO paste keystroke — this is clipboard-only, not inject.
   proc = subprocess.run(['pbcopy'], input=text.encode('utf-8'), capture_output=True, timeout=5)
   if proc.returncode != 0:
     logger.error("pbcopy failed (rc=%d)", proc.returncode)

7. _inject_via_clipboard(text: str) → None (private):
   Write text to clipboard via pbcopy, then simulate Cmd+V:
   proc = subprocess.run(['pbcopy'], input=text.encode('utf-8'), capture_output=True, timeout=5)
   if proc.returncode != 0:
     logger.error("pbcopy failed (rc=%d): %s", proc.returncode, proc.stderr.decode(errors='replace').strip())
     return
   logger.debug("Pasting via Cmd+V")
   with self._controller.pressed(keyboard.Key.cmd):
     self._controller.tap(keyboard.KeyCode.from_char('v'))

Important pitfall avoidance:
- Controller.type() must NOT be called with strings containing control characters (newlines submit terminal commands). _sanitize_text() handles this — call it before any type() call.
- subprocess.run(['pbcopy'], input=...) closes stdin automatically. Do NOT use Popen without communicate() for pbcopy.

Use from __future__ import annotations. Use logger = logging.getLogger(__name__). Follow pyright strict-mode conventions. Type-annotate all method signatures.
